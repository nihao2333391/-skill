# 校园活动策划案 Skill

这是面向高校活动策划案的一体化 Skill。用户只需选用一个 Skill；入口根据任务和对话进度，依次处理框架、内容、全文确认、Markdown 交接和 Word 排版。

## 从仓库取用

在支持导入 Skill 的客户端中，导入本目录 `campus-activity-planning/`，确保同时包含 `SKILL.md`、`references/` 和 `scripts/`。若客户端支持读取公开仓库目录，可提供本目录链接，并要求读取 `SKILL.md` 及其中引用的文件。若只读取单个文件，请按 `SKILL.md` 的相对路径一并提供 `references/`；否则技能规则会缺少必要知识。

豆包的技能入口和仓库导入能力可能随客户端版本而变。若链接导入不可用，可把本目录作为完整 Skill 包上传或导入。新对话中重新选用该 Skill，并用一句话交代活动信息和当前阶段，例如：“继续冬至活动策划，框架已确认，开始填写工作安排。”

## 工作阶段

1. 提供活动目标、事项和已知条件后，AI 生成有针对性的一级、二级标题框架，必要时为宽泛标题补充简短内容方向，等待确认。
2. 框架确认后，按一级标题逐模块询问、整理和确认。AI 忠实保留用户给出的事实，不自行补写。
3. 所有模块完成专门询问和确认后，AI 在对话框展示全文并等待用户确认。
4. 全文确认后，AI 按 `references/handoff/策划案格式交接规范.md` 生成 Markdown。用户要求 Word 排版时，进入格式模块。

## Word 排版环境

`scripts/` 中的格式程序要求 Windows、Microsoft Word 和 `references/formatting/format-rules.md` 列出的字体。豆包可读取格式规则并判断输入结构；实际生成 Word 需要能够运行本地脚本的环境。运行环境不可用时，交付已确认的 Markdown，并明确说明尚未生成 Word。

本包不包含原始策划案、通知或工作手册。`references/knowledge/sources.md` 记录知识来源类型、案例范围和章节位置；原始材料仅在开发公共材料中供维护者查阅。
