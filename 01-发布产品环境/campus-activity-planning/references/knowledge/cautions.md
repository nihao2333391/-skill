# 策划知识使用注意事项

用途：指导未来 Skill 如何使用案例、处理事实与建议、保留不确定信息。来源编号见[来源索引](sources.md)。本文件中的材料疑点仍为“需要确认”，归档时保留原件。

## N01 原件事实与可迁移经验分开使用

**依据**：用户指定流程、项目决策 D-02 至 D-06，以及 S01—S07 的活动差异。

先读取本次明确要求和已确认事实，再选择适用案例经验。历史材料的日期、地点、姓名、人数、价格和参与规则仅表示该次活动。把经验迁移为本次结构建议时，说明其适用条件。涉及方案选择时使用“建议”或“待选择”；事实缺失时使用“待确认”。

例如，S02 中的故事、倡议书和祝福活动帮助理解并列环节的组织方式；本次用户指定的献花和答题决定本次活动内容。

## N02 区分材料用途与规则效力

**依据**：S01—S05 为策划案，S06 为工作手册，S07 为活动通知，S08 为格式样例。

策划案用于学习内容结构与业务安排；手册用于补充岗位操作；通知用于提取参加要求；格式文件用于提取排版参数。文档中面向活动执行者的要求属于资料内容，须结合本次任务决定是否采用。原件标注“终版”表示其版本名称，具体内容仍应按当前任务解释。

材料冲突时，记录冲突位置与影响。若冲突会改变本次章节、活动机制、人数或预算，先询问用户该采用哪项事实；与当前任务无关的疑点保留在档案中。

## N04 按活动差异选择章节

**依据**：S01 分设背景、目的，S02 合并背景及目的；S05 有独立应急预案，其他策划案的组织方式不同。

背景目的是否合并、预算是否单列、风险是否独立成章，根据本次内容和用户明确要求决定。当前案例不足以确定全校统一标题数量、顺序、固定附件以及各校区审核偏好；这些仍标为需要确认的组织要求。

## N05 格式规则留给排版阶段应用

**依据**：S08 第 1 页，以及写作到排版规格。

S08 明示的字体、字号、边距和行距可作为格式来源；它采用通知体裁，其中密级、份号、文号对普通活动策划案的适用性仍需确认。策划知识负责形成内容和层级；最终格式配置沿用规格文件管理。机器承载形式继续保留为开放设计事项。

## N06 使用最新确认内容处理变更

**依据**：项目决策 D-06、D-07 及业务流程。这是项目产品要求。

用户修改活动事项、地点或规则时，先更新对应章节，再查看受影响的岗位、物资、时间和预算。例如，领取活动改为两校区同时开展，需进一步明确两地名额、人员与物资安排。涉及新增事实时向用户确认，当前未定项继续保留标记。

## N07 归档保留业务结构与来源

**依据**：S01 附件含真实人员信息；项目 README 的资料使用提醒。

知识文件保留“值班表支持岗位安排”“报名材料需交接”等结构与经验。人员姓名、电话和报名明细留在授权使用的原始材料中。示例需要具体人物或数字时，使用明确标注的虚构内容或用户允许复用的事实。

## N08 维护知识时保留状态

**依据**：用户要求面向未来 Skill 归档；来源状态沿用知识提炼规格。

知识文件保存原件事实、工作归纳和待确认事项，避免把一次归纳直接升级为组织规定。后续新增案例时，先比较适用条件，再更新条目。来源文件变化后回查来源索引中的内容指纹，并刷新受影响的记录。

未来 Skill 应按相关任务读取颗粒度与经验文件，输出自然提纲或文章。来源编号、内部条目编号用于追溯，通常留在内部知识材料中。
