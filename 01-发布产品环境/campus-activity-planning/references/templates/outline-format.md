# 可读提纲的展示格式建议

只是一种人类阅读视图，非必须的机器接口。

```markdown
# ××主题活动策划案（框架草稿）

## 一、活动背景及目的
内容方向：……
待补充：……

## 二、活动时间
已知：……

## 三、活动地点
已知：……
待补充：……

## 四、活动内容
### （一）事项A
已知：……
待补充：……
### （二）事项B
已知：……
待补充：……

## 五、工作安排
内容方向：……

## 六、注意事项
内容方向：……
```

生成前，先按本次实际任务决定章节是否存在、是否合并；二级标题优先对应活动模块或相对独立的实施环节。展示时一级用“**一、**”等常规编号，二级用“**（一）**”，也可映射为 Markdown 的 `##/###` 供界面渲染。
