# 高校活动策划案 Skill 项目

本仓库包含一套面向高校活动策划案的统一 Skill，以及它的开发资料。发布包位于 `01-发布产品环境/campus-activity-planning/`；使用者应从该目录获取 Skill，不需要加载开发环境。

## 目录说明

```text
项目根目录/
├── README.md                         项目入口与目录说明
├── LICENSE.md                        文档与代码的许可说明
├── 01-发布产品环境/
│   └── campus-activity-planning/     可独立使用的统一 Skill
└── 02-开发产品环境/
    ├── 00-Skill开发公共材料/         共用知识、规格、案例原件和交接约定
    ├── 01-Skill1-策划案撰写/         策划内容模块的开发源文件
    └── 02-Skill2-格式排版/           Word 格式模块的开发源文件
```

“大公共资料”由本说明、许可和其他根目录说明文件组成，不是单独文件夹。策划案知识、模板及交接规范的维护源放在开发环境的 Skill 公共材料中；发布包只带运行时需要的整理版资料。

## 产品使用

统一 Skill 按阶段处理任务：先设计并确认框架，再逐模块补充和确认内容；全部模块完成后先展示全文并等待确认，再生成 Markdown 交接稿。用户已有确认稿并提出 Word 排版需求时，Skill 转入格式模块。

豆包用户可尝试通过“技能”入口添加 `01-发布产品环境/campus-activity-planning/`，或在对话中提供该发布目录的仓库链接并要求读取其中的 `SKILL.md` 和 `references/`。如果豆包当前入口不能读取仓库目录中的多文件，按产品目录 README 的导入说明逐项提供文件。新对话中重新选用技能，并说明当前任务和已完成阶段。

Word 格式模块附带本地脚本，依赖 Windows、Microsoft Word 和指定字体。不能访问这些运行条件时，统一 Skill 仍可完成内容协作和 Markdown 交接；Word 文件需在具备运行环境的电脑上生成。

## 开发与发布

- `02-开发产品环境/00-Skill开发公共材料/README.md` 说明共用知识、案例原件、产品规格和交接规范。
- 重组前的 `.agents/skills/` 原始入口保存在 `02-开发产品环境/00-Skill开发公共材料/历史Skill入口备份/`，仅供追溯。
- 两个 Skill 开发目录分别维护策划内容与 Word 格式模块；统一发布 Skill 的阶段路由以 `01-Skill1-策划案撰写/SKILL.md` 为主要开发源。
- 发布资料必须自包含，引用路径只指向发布包内部文件。原始策划案、工作手册和通知留在开发公共材料中，不复制到发布包。
- 本仓库保留格式验证输出和研发记录；它们不属于 Skill 的导入内容。
