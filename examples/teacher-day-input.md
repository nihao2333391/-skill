# 业务测试 1：教师节活动，仅给少量信息

## 用户第一轮输入（测试用，不代表已批准方案）

“我们想做一个教师节活动，主要有老师献花和现场互动答题，地点是各校区大学生活动中心。策划案按学生会惯用的写法来，具体规则还没完全确定。”

## 第一轮正确工作方式

1. 识别目标：尊师主题、提高学生参与互动（后者可能只是合理推断，需与用户核对）。
2. 明确已知事实：有两个活动事项；地点范围已知；具体执行细节待补。
3. 从两个活动事项推导参与者、实施流程、物资、现场安排等业务问题。
4. 提供一级、必要二级标题框架和各部分待补内容。
5. 用户确认后再逐章撰写，避免将想象的奖品、人员、数量写成已确定事实。

## 第二轮追加信息（用于回归测试）

“现场答题分三个难度盒子，每题最多两次，奖励按积分兑换；活动以互动参与为主。”

预期：重点丰富互动答题子章节的机制及物资需求，其他已经确定的背景、地点等信息保持稳定。
