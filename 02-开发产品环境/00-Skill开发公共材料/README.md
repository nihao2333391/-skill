# Skill 开发公共材料

这里保存两个开发模块共同使用的维护源和项目记录：

- `knowledge/`：历史案例提炼出的框架、活动经验、颗粒度、来源及注意事项。
- `templates/`：任务信息识别和框架展示参考。
- `交接规范/`：策划内容模块交给格式模块的 Markdown 契约。
- `decisions/`、`specs/`、`examples/`：已确认决策、需求规格和开发案例。
- `原始案例材料/`：研究使用的原始策划案、通知、手册及格式依据；不属于发布包。
- `tests/`：跨模块测试场景。

`knowledge/`、`templates/` 和交接规范是发布包参考资料的维护源。运行 `scripts/build_release.ps1` 可将当前 Skill 1 入口、共用知识和 Skill 2 排版模块同步到发布包；脚本会检查包内 Markdown 链接，并阻止原始 PDF/DOCX 进入发布目录。不要把原始案例文件或含个人信息的内容复制到发布目录。
