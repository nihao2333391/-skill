# 活动信息采集：动态引导参考（非强制表单）

从用户已有表达里直接提取相关信息；缺少时只询问当前会影响框架或方案设计的内容。

| 信息维度 | 提取/追问例子 | 何时重要 |
|---|---|---|
| 活动目的 | 为什么开展？希望产生什么结果？ | 框架生成前最优先 |
| 已确定事项 | 明确做哪几件事？上级要求有哪些硬约束？ | 影响活动内容章节 |
| 参与对象 | 面向谁？由谁开展？ | 宣传、互动、报名等活动 |
| 时空条件 | 什么时间、哪个校区或场地？ | 多校区/现场类活动 |
| 流程规则 | 参与方式、环节时间、评分兑换、资料流转等 | 活动机制需要落地 |
| 责任与资源 | 人员安排、物资、预算或设施 | 有协作、采购和现场管理 |
| 注意事项 | 人员安全、资料保护、场地秩序、突发事件 | 有对应风险时 |
| 活动交付 | 完成后交接什么、如何归档或汇总？ | 有数据/报名/志愿者等交付 |
| 参考文件 | 有没有现成类似方案/通知？ | 可选，不依赖 |

**推荐对话方式**：先回应“我理解本次主要是……”，给出活动框架；对于真正阻碍框架生成的核心事实，可先问一个简短问题。其余缺口集中到框架对应章节逐步填充。
