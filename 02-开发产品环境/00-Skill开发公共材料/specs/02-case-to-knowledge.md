## A. 真实招新策划案（`原始案例材料/2026-2027_志愿者招新活动策划案.pdf`）

### [来源明确] 标题及组织方式（原 PDF 第 1—3 页）

1. 一、活动背景
2. 二、活动目的
3. 三、活动时间
4. 四、活动地点
5. 五、参与人员
6. 六、工作安排：下设（一）线上通知、（二）点位招新、（三）材料汇总
7. 七、所需材料
8. 八、工作注意事项
9. 九、后续工作说明

第 3 页列落款、日期及附件说明；第 4 页为招新点位值班表。工作安排中还通过 1.、2.、3. 表达具体执行事项。

### [来源明确] 业务要素（按原件归纳）

| 本次招新的业务关切 | 原件写出的内容 |
|---|---|
| 为什么举办 | 宣传学生会、招募项目化志愿者、规范收集报名信息 |
| 招募对象 | 重点年级及对象范围 |
| 组织实施 | 线上群通知、两个校区固定招新点位、现场宣传、报名表接收 |
| 资源准备 | 旗帜、手册、二维码、报名表、收纳箱、文具 |
| 质量与风险 | 按时到岗、资料保管、信息保护、物资收纳、突发协调 |
| 收尾交付 | 统计报名信息、材料归档、后续遴选 |

### [工作归纳] 有条件迁移的业务分析框架

`目标 → 活动事项/实施路径 → 时间地点/参与者/责任人 → 物资与资源 → 风险或工作注意 → 成果交付/后续安排`。

这是从招新案例提炼的**分析维度**，不代表每份策划案都要按这些词设一级标题；简单任务可合并，特殊任务可以增加对应章节。

### [需要确认] 不能由一个案例推断的事项

- 所有学生会策划案的固定章节数量和顺序；不同类型活动是否有必选附件；各校区审批偏好；预算、宣传、应急预案是否必须独立成章。
- 类似主题出现时，是否有专门部门模板可优先采用。

## C. Skill 知识应如何提炼

建议按“**知识条目 + 适用场景 + 来源/可信级别 + 提问触发条件**”组织，而非只有固定的策划案大纲。例如：

- 条目：涉及现场报名材料时，需要明确收集、保管、交接和后续归档。
- 条件：存在现场报名/个人信息收集。
- 来源：招新策划案第 2—3 页。
- 行为：在生成框架时考虑“报名工作安排”“材料与信息管理”，按需要合并或展开。

当没有历史同类策划案时，Skill 利用通用业务维度与当前任务信息生成第一版框架；用户给到类似案例时，再提高适配精度。
