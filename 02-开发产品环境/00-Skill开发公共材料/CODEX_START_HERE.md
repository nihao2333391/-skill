# Codex 开发入口

项目的唯一对外入口是 `01-发布产品环境/campus-activity-planning/`。该目录将策划案撰写与 Word 格式处理整合为一个 Skill；开发过程仍分为两个模块。

## 资料位置

- `decisions/DECISIONS.md`：已确认的业务要求和仍开放的设计问题。
- `specs/`：产品边界、知识提炼、业务流程、交接结构、验收和开发计划。
- `knowledge/`：从历史案例提炼的框架逻辑、颗粒度、活动经验和注意事项。
- `templates/`：任务信息识别与框架展示参考。
- `原始案例材料/`：开发期原始 PDF、DOCX 和工作手册，不复制到产品发布包。
- `交接规范/策划案格式交接规范.md`：撰写阶段与格式阶段之间的 Markdown 契约。
- `../01-Skill1-策划案撰写/`：统一入口和策划内容模块开发源。
- `../02-Skill2-格式排版/`：Word 格式模块开发源、脚本和测试。

## 更新发布包

维护知识时先更新 `knowledge/`；更新流程时检查业务决策和规格；更新排版时检查交接规范及 Skill 2 测试。完成开发修改后，将需要的内容同步到发布目录，并检查包内引用和运行依赖。发布包映射见 `PACKAGE-MAP.md`。

原始案例只用于核对证据，不把案例中的个人信息、日期、人员、数量或价格复制为通用规则。
