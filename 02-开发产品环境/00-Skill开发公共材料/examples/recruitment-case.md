# 业务测试 3：根据原始招新策划案进行反向分析

来源：`原始案例材料/2026-2027_志愿者招新活动策划案.pdf`

## 参考材料的业务内容

- 主要目标：宣传学生会工作、招募项目化志愿者、收集与汇总报名材料。
- 内容主线：线上通知 → 校区点位宣传与报名收取 → 材料汇总 → 后续遴选说明。
- 条件：时间、场地、负责人、对象、物资、注意事项。
- 附件：值班表。

## 要求 Codex 演示的能力

1. 从已成稿案例反推出“该活动所需解决的业务问题”而不只摘标题。
2. 把具体章节与执行目的建立对应关系：例如资料保管来自报名信息收集的要求。
3. 将知识迁移到相近场景时保留抽象业务逻辑；迁移到不同活动时合理调整章节。
4. 允许用户提供自己习惯的章节名称和顺序，按本次任务调整。

## 结构基线（来源明确）

一级标题共九个：活动背景、活动目的、活动时间、活动地点、参与人员、工作安排、所需材料、工作注意事项、后续工作说明。工作安排下有三项二级标题：线上通知、点位招新、材料汇总。
