# 项目知识资源索引

此 Skill 与项目知识库配套使用。以下路径相对 Skill 目录中的 `references/`，用于在本项目工作区读取原始知识，不复制个人信息或原始策划案附件。

- `../../../../knowledge/framework-design-research.md`：跨案例研究、真实章节与活动需求的联系、新活动框架构建方法。
- `../../../../knowledge/content-granularity.md`：一级/二级标题、正文条目和表格的颗粒度判断。
- `../../../../knowledge/activity-experience.md`：招募报名、主题互动、仪式、迎新、通知、预算等经验及触发条件。
- `../../../../knowledge/cautions.md`：来源事实与推导区分、案例疑点、事实边界和材料使用注意事项。
- `../../../../knowledge/sources.md`：案例编号、文件来源和章节/页码索引。
- `../../../../templates/outline-format.md`：讨论框架的可读展示参考。
- `../../../../templates/task-intake.md`：任务信息识别维度。它是动态参考，不是强制填写表单。
- `../../../../formatting-skill-workspace/策划案格式交接规范.md`：用户确认全文后的 Markdown 交接规范。

使用知识时，先依据本次任务选择相关经验。历史案例帮助校准当地惯例和颗粒度，不构成所有活动的固定目录；具体来源和适用边界见知识库文件。
