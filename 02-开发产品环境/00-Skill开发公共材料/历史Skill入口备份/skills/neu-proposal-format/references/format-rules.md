# 格式规则与依据

## 规则优先级

1. `explicit`：`references/公文格式要求.pdf` 明确写出的参数。
2. `sample_default`：该规范没有写明、从 `references/2026年教师节策划案.pdf` 观察并用于首版的默认值。

样本默认值用于生成首版成品，但不得描述为《公文格式要求》的原文规定。

## 规范明确参数

| 对象 | 参数 |
|---|---|
| 页面边距 | 上 39mm、下 33mm、左右 27mm |
| 主标题 | 21 磅、方正小标宋_GBK、固定行距 35 磅 |
| 一级标题 | 17 磅、方正黑体_GBK |
| 二级标题 | 17 磅、方正楷体_GBK |
| 三级内容 | 17 磅、方正仿宋_GBK |
| 正文 | 17 磅、方正仿宋_GBK，数字使用 Times New Roman |
| 正文行距 | 固定 28.95 磅 |
| 页码 | 小四号、Times New Roman，左右各一条一字线，距页面底部 20mm |

## 教师节样本默认值

- A4、纵向。
- 主标题居中，多行标题放在同一标题段中，以换行符分隔。
- 一级、二级标题独立成段、左对齐，不额外加粗。
- 普通正文和三级内容首行缩进两个汉字，即 34 磅。
- 一级、二级标题不缩进。
- 所有段落段前、段后均为 0。
- 除主标题外，各类文字使用固定 28.95 磅行距。
- 普通正文两端对齐。
- 落款单位和日期各占一行、右对齐，使用正文样式。
- 页码从第一页开始，页脚居中，显示为 `— 1 —`。
- 原稿编号作为可见文字保留，程序不重新编号。

## 字体与运行环境

正式生成前必须检测以下字体族：

- 方正小标宋_GBK
- 方正黑体_GBK
- 方正楷体_GBK
- 方正仿宋_GBK
- Times New Roman

缺少任一规定字体时停止。程序不安装字体，也不使用近似字体代替。

Microsoft Word 是首版页面验收软件。DOCX 必须由 Word 导出为 PDF，再转为逐页 PNG 供 Agent 检查。

## 内容保持

- 去除结构标记后，DOCX 的可见正文必须与输入逐段一致。
- 保留全角、半角标点和原有数字形式。
- 不自动修改用词、日期、编号或组织名称。
- Markdown 标记、主标题边界和落款标记不得进入 DOCX。
