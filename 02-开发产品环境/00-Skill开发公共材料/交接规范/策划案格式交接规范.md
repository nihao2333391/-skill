# 东北大学策划案格式设置 Skill：撰写交接规范

## 1. 最终目标

格式设置 Skill 接收策划案撰写 Skill 按双方约定交出的完整稿件，生成符合《公文格式要求》的可编辑 Word 文档。

## 2. 当前状态与后续工作

项目已经形成格式设置 Skill 初版，能够检查约定结构的 Markdown、生成可编辑 Word，并输出机器核验和页面预览材料。本文件作为撰写 Skill 与格式设置 Skill 之间的共享交接依据。

后续根据真实使用情况继续核对输入边界、格式参数、不同 Word 环境下的页面效果和异常处理。样例及每轮验证产物分别存放在 `samples/` 与 `outputs/`。

## 3. 输入来源与处理范围

- 唯一输入来源是遵守本约定的策划案撰写 Skill。
- 输入稿件已经完成内容撰写和人工确认。
- 处理对象是纯文字策划案，最多使用三级样式。
- 当前不处理表格、图片、附件正文和段内标签。
- 当前格式依据限定为项目中的《公文格式要求》。

## 4. 上游稿件规则

### 4.1 主标题

主标题使用以下边界标记：

```markdown
【主标题开始】
第一行标题
第二行标题
【主标题结束】
```

- 标记内部可以有一行或多行标题文字。
- 标题的顺序和指定分行属于输入信息，必须保留。
- 边界标记只用于交接，不属于最终文档正文。

### 4.2 一级标题

一级标题使用 Markdown 二级标题标记 `##`，并保留中文序号：

```markdown
## 一、活动背景及目的
```

### 4.3 二级标题

二级标题使用 Markdown 三级标题标记 `###`，并保留带括号的中文序号：

```markdown
### （一）具体活动
```

### 4.4 三级项

三级项使用段首阿拉伯数字、英文句点和完整内容：

```markdown
1.工作人员应提前到达现场，完成物资清点和设备检查，并向负责人报告准备情况。
```

- 一个三级项对应一个自然段。
- 一个三级项可以包含多句话。
- 三级项可以直接位于一级标题或二级标题之下。
- 三级项当前理解为使用三级样式的内容展开段落，不要求它先以短标题形式出现。

### 4.5 普通正文与段落

- 普通正文直接书写，不增加对象标签。
- 每个标题独立成段。
- 不同自然段之间保留一个空行。
- 同一自然段内部连续书写；由页面宽度产生的自动换行不写入交接稿。
- 分页不改变自然段边界。成稿中跨页接续的同一段，在交接稿中恢复为一个连续自然段。

### 4.6 落款

落款位于全文末尾，使用以下格式：

```markdown
【落款】
单位名称
成文日期
```

- 第一行是落款单位。
- 第二行是成文日期。
- `【落款】` 只用于交接，不属于最终文档正文。

### 4.7 交接形式

- 正式交接必须保留原始 Markdown 文本。
- 优先交付 UTF-8 编码的 `.md` 文件。
- 通过对话交接时，应把完整原始稿放入代码块，避免 `##`、`###`、空行和特殊边界标记丢失。

## 5. 中游待实现职责

格式设置 Skill 后续需要：

1. 检查输入是否满足本约定，并指出具体不符合位置。
2. 识别主标题、一级标题、二级标题、三级项、普通正文和落款。
3. 将识别结果映射到《公文格式要求》中的对应规则。
4. 生成可编辑 Word 文档。
5. 核对原稿与成品的文字、数字、标点、顺序和段落关系。
6. 检查文档内部格式属性和实际页面显示效果。

## 6. 下游目标

下游交付可编辑 Word 文档及格式核验结果。验收至少覆盖：

- 内容保持：原稿的文字、数字、标点、顺序和段落关系完整保留。
- 格式符合：适用的页面、字体、字号、行距等参数符合最终确认的规则。
- 页面效果：文档在目标查看环境中显示完整，分页合理，没有文字缺失或异常换行。
