# Skill 2：格式排版模块

本目录维护已确认 Markdown 稿件的检查、Word 生成、机器核验和页面检查流程。它在开发环境中单独迭代，在发布产品中作为统一策划案 Skill 的后续阶段使用。

- `SKILL.md`：格式处理模块规则。
- `references/`：输入契约、格式参数和格式规则。
- `scripts/`、`tests/`：Word 生成代码及其测试。
- `samples/`、`outputs/`：格式输入样例和开发验证材料，不随发布包提供。

共享交接规范位于同级 `../00-Skill开发公共材料/交接规范/`。Word 生成依赖 Windows、Microsoft Word 和指定字体；其他平台可使用统一 Skill 完成内容与 Markdown 交接。
