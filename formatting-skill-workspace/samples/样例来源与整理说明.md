# 2026 年教师节策划案初始样例说明

## 1. 来源

原始成稿：`references/2026年教师节策划案.pdf`

待处理样例：`formatting-skill-workspace/samples/2026年教师节策划案-格式输入样例.md`

## 2. 用途

本样例用于确定格式设置 Skill 的上游输入特征，并作为后续输入检查、对象识别、DOCX 生成和结果核验的初始测试对象。

样例采用 `formatting-skill-workspace/策划案格式交接规范.md` 中已经确认的输入规则：

- 主标题使用成对边界标记并保留原有分行。
- 一级标题使用 `##`。
- 二级标题使用 `###`。
- 普通正文不添加对象标签。
- 自然段之间保留空行。
- 落款使用 `【落款】` 标记，后接单位和日期。

## 3. 从成稿到输入样例的整理

- 保留两行主标题。
- 保留第一至第九章及三个二级标题的全部文字内容。
- 按已确认的纯文字范围，整章排除“十、活动预算”及其表格。
- 保留文末落款单位和成文日期。
- 移除页码和分页信息。
- 合并页面排版产生的行内换行，保留自然段边界。
- 将第二、三页之间接续的“九、人员安排”首段恢复为一个连续自然段。
- 去除成稿中为版面字距产生的字符间空隙，保留原有措辞、编号、数字和标点形式。
- 输入文件只保存待处理稿件；来源、裁剪和测试信息集中记录在本说明中。

## 4. 当前覆盖情况

本样例已经覆盖：

- 双行主标题。
- 九个一级标题。
- 三个二级标题。
- 长正文、短正文和同一标题下的多个自然段。
- 跨页接续后恢复为连续自然段的情况。
- 文末单位和日期组成的落款。

本样例尚未覆盖：

- 三级编号段落。
- 表格、图片和附件正文；这些对象目前属于 Skill 范围之外。

## 5. 样例状态

本文件是根据 PDF 页面人工对照整理的初始输入样例，尚未经过格式设置 Skill 的实际转换验证。后续测试需要保存解析结果、生成的 DOCX、内容核对结果、格式属性检查结果和页面预览结论。
